# 💊 MediBox -- Medicine Expiry Tracker

**A Smart Medicine Management System**

MediBox is a web-based medicine management application designed to help
users organize their medicine inventory, monitor expiry dates, and avoid
using expired medicines. It provides a simple, user-friendly dashboard
to manage medicines efficiently.

## 🚀 Key Features

-   **Medicine Inventory Management:** Add, view, update, and delete
    medicine records.
-   **Expiry Date Tracking:** Monitor the expiry dates of stored
    medicines.
-   **Expiry Status Indicators:** Identify medicines that are safe,
    expiring soon, or expired.
-   **Search Functionality:** Quickly find medicines by name.
-   **Category Filtering:** Filter medicines by category.
-   **Dashboard:** View and manage the medicine inventory in one place.
-   **Local Data Storage:** Store medicine records in the browser using
    Local Storage.
-   **User-Friendly Interface:** Clean and easy-to-use design.

## ⚙️ Installation & Setup

### 1. Clone the repository

``` bash
git clone https://github.com/your-username/medibox.git
```

### 2. Navigate to the project directory

``` bash
cd medibox
```

### 3. Run the application

Open `medibox.html` in your preferred web browser.

Alternatively, open the project folder in Visual Studio Code and run the
page using the Live Server extension.

## 💡 How It Works

1.  Open the MediBox application.
2.  Enter medicine details, such as name, category, quantity, and expiry
    date.
3.  The application stores medicine information in browser Local
    Storage.
4.  The system checks the expiry dates.
5.  Medicines are identified according to their expiry status.
6.  Search, filter, edit, or delete medicine records as needed.
